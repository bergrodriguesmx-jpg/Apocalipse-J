# 🧟 ECOZUMBI

Simulador isométrico de ecossistema rural pós-apocalíptico com física realista, desmembramento balístico e três armas de fogo.

## 🎮 Controles

- **WASD / Setas** — mover
- **Clique** — usar ferramenta ativa (machado, arma, plantar, etc.)
- **Arrastar mouse** — orbitar câmera
- **Scroll** — zoom
- **Pistola / Rifle / Escopeta** — clique na direção do alvo

## 🔫 Armas

| Arma | Dano | Cadência | Notas |
|---|---|---|---|
| Pistola | 50 | 0.35s | Precisão média |
| Rifle | 85 | 0.15s | Alta cadência |
| Escopeta | 30 × 7 | 0.9s | Spread grande |

## 🚀 Rodar localmente

Basta abrir `index.html` no navegador. Todos os CDNs carregam por HTTPS — não precisa de servidor.

## 🌐 Deploy GitHub Pages

1. **Settings → Pages**
2. Branch `main`, folder `/ (root)`
3. Acesse `https://SEU_USUARIO.github.io/SEU_REPO/`
